### Baseline errors (Django 5.2 + model-bakery 1.17.0)

There were 3 errors, all in `biblioref.tests.BiblioRefDeleteViewTest.setUp`, from `baker.make(...)`:
- `test_delete_reference`
- `test_delete_reference_of_another_user_not_allowed`
- `test_delete_source_with_analytics_not_allowed`

Each raised:

```
TypeError: field content_object type <class 'django.contrib.contenttypes.fields.GenericForeignKey'> is not supported by baker.
```

Django 5.1 made `GenericForeignKey` a real model field, and model-bakery 1.17.0 doesn't know how to generate it. This is a test-tool incompatibility rather than an app breaking change, and model-bakery 1.24.2 fixes it. **No failures were left to record for task 5.4.**

### Incident: leftover smoke-test user (cleaned up)

The authenticated smoke checks created a temporary superuser `smoke_tmp` inside `transaction.atomic()`, expecting a rollback. The dev DB tables are **MyISAM**, which doesn't support transactions, so the user (id 1948), its auto-created `biremelogin.Profile` and one `django_session` row were committed. All three were deleted manually right after; no admin `LogEntry` rows were created. The only lasting trace is that the `auth_user` AUTO_INCREMENT advanced.
